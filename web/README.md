# web/ — the courtroom UI

A simple page that reads one job and shows the whole proceeding: the brief, the
submitted work, the agreed checklist, the panel's per-item findings, the final
verdict with evidence links, and the reputation written on-chain.

Reuses Tribunal's visual language (panel cards, verdict block, evidence links).
Built in Phase 4; deploy to Render/Vercel for a public link.
